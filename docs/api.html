API HTTP

JSON sur HTTP, identité par en-tête. Le schéma OpenAPI complet est servi en mode debug.

Authentification#

X-User-UID: 0192f0c4-7d7a-7c1e-9a0b-5d2c8e1f3a47

Requis pour la progression, les notes et les documents d'un chapitre. Publics : santé, /auth/*, lecture des formations, /videos/* et le téléchargement /docs/{id}/file. Avec APP_DEBUG=true, un UID fixe remplace l'en-tête absent, et l'interface OpenAPI est servie sur /api-docs, /api-redoc et /openapi.json.

# UID est une variable réservée de bash : on utilise un autre nom
LEARNER=$(curl -s -X POST localhost:8000/auth/generate | jq -r .uid)
curl -s localhost:8000/progress/formations -H "X-User-UID: $LEARNER"

Les listes ne sont pas paginées : GET /formations renvoie le catalogue complet, chapitres et leçons compris.
