Présentation

Une plateforme e-learning open source et auto-hébergée, avec une couche IA intégrée aux formations.

Catalogue → formation → assistant → lecteur et notes → studio.

Cours filmé : les présentations officielles des versions de Blender, publiées sur la chaîne YouTube de Blender et réutilisées sous licence Creative Commons Attribution.

E-Learning repose sur trois piliers :

  • E-learning. Des formations découpées en chapitres, avec leçons vidéo ou audio et documents ; progression et notes horodatées pour chaque apprenant ; un studio pour construire les formations.
  • Auto-hébergement. Toute la pile se déploie avec Docker Compose ; médias, base et index restent sur votre infrastructure.
  • IA. Transcription des leçons, résumés et assistant par formation qui cite ses sources, avec le modèle de langage de votre choix, local ou distant.

Pour qui#

Pour un usage personnel (suivre sa bibliothèque de cours) ou une équipe de confiance (formations internes, onboarding) sur un réseau privé. Ce n'est pas un LMS commercial : pas de comptes avec mot de passe, pas de rôles, pas de vente ni de certification. Le détail est sur la page d'accueil.

Le projet se compose de trois applications et d'une poignée de services :

Fonctionnalités#

  • Parcours apprenant

    Catalogue, reprise de lecture, progression, notes horodatées, documents.

  • Studio

    Formations, chapitres, téléversement, réordonnancement, conversion ffmpeg.

  • Catalogue sur disque

    Les fichiers restent lisibles dans un dossier ; la base se réconcilie avec lui.

  • Transcription et IA

    Transcription, résumés de leçon, questions sur la formation avec sources.

  • Mobile

    Le parcours apprenant en application native.

  • Exploitation

    CLI, worker, migrations, sauvegardes.

Le modèle en une minute#

  • Formation → Chapitre → Vidéo / Document. L'ordre est une colonne position en base : réordonner ne renomme aucun fichier.
  • Un apprenant = un UID. Un UUID généré à la première visite, envoyé dans l'en-tête X-User-UID. Il porte la progression et les notes.
  • Les traitements lourds sont des jobs. Conversion, transcription, résumé et indexation passent par RabbitMQ et un worker ; l'interface affiche leur avancement.
  • Transcriptions et résumés sont des fichiers. Ils sont écrits à côté du média (leçon.txt, leçon.md), donc versionnables, éditables, et portables d'une instance à l'autre.

Démarrage rapide#

git clone https://github.com/EdwinAlkins/e-learning.git
cd e-learning
cp .env.template .env
docker compose up -d --build
# → http://localhost:3000

Aucun modèle d'IA n'est requis pour démarrer ; résumés et assistant s'activent quand vous en branchez un.

Une instance de confiance Il n'y a ni mot de passe ni rôle : quiconque atteint le front peut ouvrir le studio. Gardez l'instance en local ou derrière une authentification ; voir Exposer l'instance.
